## 🤔 Зачем это было создано?

В интернете полно сервисов для конвертации картинок в PDF. Но у всех них есть одна огромная проблема: **вам нужно загружать свои личные фото, документы или сканы на чужие сервера**. 

Этот проект решает эту проблему. **PDF Конвертер** работает на 100% на стороне клиента (в вашем браузере). Ваши файлы никогда не покидают ваш компьютер. Это просто красивый и удобный интерфейс поверх мощной JavaScript-библиотеки.

## ✨ Фишки и возможности

- 🛡️ **Абсолютная приватность:** Вся магия происходит в вашем браузере. Файлы никуда не отправляются.
- 🖱️ **Удобный Drag & Drop:** Просто перетащите папку или файлы в окно браузера.
- 🖼️ **Широкая поддержка форматов:** PNG, JPEG, GIF, WEBP, BMP, TIFF, SVG и даже специфичные `.do` файлы.
- ⚙️ **Гибкие настройки:**
  - Выбор размера страницы (A4, Letter, A3 или «По размеру изображения»).
  - Настройка ориентации (Авто, Книжная, Альбомная).
  - Регулировка качества (сжатия) для оптимизации веса итогового PDF.
- 🔄 **Манипуляции с файлами:** Поворот изображений на 90°, сортировка по имени, массовое выделение и удаление.
- 📱 **Адаптивный дизайн:** Отлично выглядит и работает как на десктопе, так и на смартфонах.
- ⚡ **Мгновенная работа:** Никаких очередей на сервере и ожидания обработки.

## 🛠 Под капотом

Проект написан без использования тяжелых фреймворков (React/Vue/Angular), чтобы оставаться максимально легким и быстрым.

* **HTML5 / CSS3:** Семантическая верстка, CSS Grid, Flexbox, CSS-переменные и плавные анимации (Cubic-bezier).
* **Vanilla JavaScript:** Чистый JS (ES6+) без зависимостей от сборщиков (Webpack/Vite).
* **[pdf-lib](https://pdf-lib.js.org/):** Отличная библиотека для создания и модификации PDF-документов прямо в браузере.
* **[Font Awesome](https://fontawesome.com/):** Для красивых иконок.

## 🚀 Как использовать

1. Откройте `index.html` в любом современном браузере (или перейдите по ссылке на GitHub Pages, если вы его задеплоили).
2. Перетащите изображения в пунктирную зону или кликните по ней для выбора файлов.
3. При необходимости настройте размер страницы, качество или поверните отдельные изображения.
4. Нажмите **«Конвертировать все в PDF»** (или выберите конкретные файлы галочками).
5. Готово! Браузер автоматически скачает готовые `.pdf` файлы.
